Fair play

Your machine belongs to you, so you can modify the agent. The game starts from that principle: the server takes nothing on trust.

The score is the observed time

The leaderboard never reads the reported uptime. It measures how long the server has seen you respond, using its own clock. A machine that reports 400 days starts at zero like everyone else.

No time travel

Nobody gains more than one second per second, and nobody can go back past their enrolment date. To show a year, you have to last a year.

Every heartbeat is signed

The Ed25519 key is generated on your machine and never leaves it. The server sends a single-use challenge, valid for one minute. A heartbeat cannot be forged, replayed or prepared in advance.

What resets the counter

A new kernel boot id, an uptime that goes backwards or drifts from the server clock, or more than {{.MaxGap}} minutes of silence. A server outage does not penalize you.

One boot, one machine

A single kernel session cannot race under two names. A key copied to two machines sabotages itself: the boot ids alternate and the streak resets to zero.

Throttled enrolment

Each enrolment costs a proof of work and is limited per IP address. Filling the leaderboard with fake accounts gains nothing: they all start from zero.

The limit, plainly

A modified agent can lie about the boot id and hide a quick reboot. It can also run on a highly available server instead of your PC. Without a trusted chip, no software can prevent this. But the cheater must still keep a program online, without interruption, for the whole displayed duration. There is no shortcut in time.
