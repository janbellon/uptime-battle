Installer l'agent

Un binaire statique, sans dépendance, qui tourne sans privilèges et ne lit que l'uptime et l'identifiant de démarrage du noyau. Linux amd64, arm64 et armv7.

Choisissez bien votre nom. De 3 à 32 caractères parmi a-z A-Z 0-9 _ . -, public et définitif. L'inscription résout un petit calcul : comptez quelques secondes.

Recommandé

systemd

Le service démarre avec la machine et envoie un battement chaque minute. À lancer en root.

curl -fsSL {{.PublicURL}}/install.sh | sudo sh -s -- --method systemd --name VOTRE-NOM

Cron

Sans service ni root : un battement toutes les cinq minutes depuis votre crontab utilisateur.

curl -fsSL {{.PublicURL}}/install.sh | sh -s -- --method cron --name VOTRE-NOM

Docker

Le conteneur lit l'uptime de l'hôte. Le volume garde la clé de la machine : le perdre, c'est perdre son identité.

docker run -d --name uptime-battle-agent --restart unless-stopped \
  --read-only --cap-drop ALL --security-opt no-new-privileges \
  -e UB_SERVER={{.PublicURL}} -e UB_NAME=VOTRE-NOM \
  -v uptime-battle:/var/lib/uptime-battle \
  {{.AgentImage}}

Manuel

Pour relire avant d'exécuter : téléchargez le binaire et vérifiez son empreinte.

curl -fsSLO {{.PublicURL}}/dl/uptime-battle-agent-linux-amd64
curl -fsSL {{.PublicURL}}/dl/SHA256SUMS | sha256sum -c --ignore-missing
chmod +x uptime-battle-agent-linux-amd64
./uptime-battle-agent-linux-amd64 enroll --server {{.PublicURL}} --name VOTRE-NOM
./uptime-battle-agent-linux-amd64 run
