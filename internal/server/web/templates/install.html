Install the agent

A static binary with no dependencies. It runs without privileges and only reads the uptime and the kernel boot id. Linux amd64, arm64 and armv7.

Choose your name carefully. 3 to 32 characters among a-z A-Z 0-9 _ . -, public and permanent. Enrolment solves a small puzzle, so allow a few seconds.

Recommended

systemd

The service starts with the machine and sends a heartbeat every minute. Run as root.

curl -fsSL {{.PublicURL}}/install.sh | sudo sh -s -- --method systemd --name YOUR-NAME

Cron

No service and no root: a heartbeat every five minutes from your user crontab.

curl -fsSL {{.PublicURL}}/install.sh | sh -s -- --method cron --name YOUR-NAME

Docker

The container reads the uptime of the host. The volume keeps the machine key: if you lose it, you lose the identity of the machine.

docker run -d --name uptime-battle-agent --restart unless-stopped \
  --read-only --cap-drop ALL --security-opt no-new-privileges \
  -e UB_SERVER={{.PublicURL}} -e UB_NAME=YOUR-NAME \
  -v uptime-battle:/var/lib/uptime-battle \
  {{.AgentImage}}

Manual

To review everything before running it: download the binary and verify its checksum.

curl -fsSLO {{.PublicURL}}/dl/uptime-battle-agent-linux-amd64
curl -fsSL {{.PublicURL}}/dl/SHA256SUMS | sha256sum -c --ignore-missing
chmod +x uptime-battle-agent-linux-amd64
./uptime-battle-agent-linux-amd64 enroll --server {{.PublicURL}} --name YOUR-NAME
./uptime-battle-agent-linux-amd64 run
